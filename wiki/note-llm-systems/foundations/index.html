Scaling Laws

2026.10.23

交叉熵，梯度下降，自注意力那些东西就不在这里赘述了。稍微挑一点 AIST5050 里我觉得有意思的东西记录一下。

C=6NDC=6NDC=6ND

设：

  • NNN：模型的 trainable parameter count。
  • DDD：训练过程中处理的 token occurrences 数量。
  • CCC：总 training compute，单位为 FLOPs。

对于 dense neural networks，可以近似估计：

Ctrain≈6ND. \boxed{C_{\mathrm{train}}\approx6ND}. Ctrain​≈6ND​.

推导过程如下，考虑一个 dense layer：

Y=WH, Y=WH, Y=WH,

其中：

W∈Rdout×din,H∈Rdin×b. W\in\mathbb R^{d_{\mathrm{out}}\times d_{\mathrm{in}}}, \qquad H\in\mathbb R^{d_{\mathrm{in}}\times b}. W∈Rdout​×din​,H∈Rdin​×b.

该层具有 NW=doutdinN_W=d_{\mathrm{out}}d_{\mathrm{in}}NW​=dout​din​ 个权重。

Forward pass 的主要矩阵乘法需要：

2doutdinb=2NWb 2d_{\mathrm{out}}d_{\mathrm{in}}b =2N_Wb 2dout​din​b=2NW​b

次 FLOPs（结果矩阵有 doutbd_{\mathrm{out}}bdout​b 个元素，得到每个元素需要 dind_{\mathrm{in}}din​ 次乘法与 din−1d_{\mathrm{in}}-1din​−1 次加法）。

Backward pass 主要计算两个矩阵乘法：

∂J∂W=GH⊤,∂J∂H=W⊤G. \frac{\partial J}{\partial W}=GH^\top, \qquad \frac{\partial J}{\partial H}=W^\top G. ∂W∂J​=GH⊤,∂H∂J​=W⊤G.

它们各自也需要大约 2NWb2N_Wb2NW​b FLOPs。

因此：

Cforward+backward≈2NWb+2NWb+2NWb=6NWb. C_{\mathrm{forward+backward}} \approx2N_Wb+2N_Wb+2N_Wb =6N_Wb. Cforward+backward​≈2NW​b+2NW​b+2NW​b=6NW​b.

对所有 dense layers 和训练 tokens 累加：

Ctrain≈6ND. C_{\mathrm{train}}\approx6ND. Ctrain​≈6ND.

这个近似模型忽略了部分 attention computation、optimizer overhead、bias operations 和 recomputation 等开销。

Chinchilla Scaling Law

Chinchilla（Hoffmann et al., 2022）研究了固定 compute budget 下的 optimal model/data allocation。其经验结论之一是，compute-optimal 模型应当在模型规模增加时同步增加训练 tokens。

在 Chinchilla 的训练设置下，这一比例为：

D∗N∗≈20. \frac{D^{*}}{N^{*}}\approx20. N∗D∗​≈20.

即每个参数对应约 20 个 training tokens。

此外，Chinchilla 的一种经验 loss model（通常关注在 held-out 数据上的 loss）为：

f^(N,D)=ffloor+ANα+BDβ \boxed{ \hat f(N,D)= f_{\mathrm{floor}}+\frac{A}{N^\alpha} +\frac{B}{D^\beta} } f^​(N,D)=ffloor​+NαA​+DβB​​

其中 A,B,α,β>0A,B,\alpha,\beta>0A,B,α,β>0。

三项分别表示：

  • ffloorf_{\mathrm{floor}}ffloor​：不可消除的基准 loss。
  • A/NαA/N^\alphaA/Nα：有限模型容量带来的 loss。
  • B/DβB/D^\betaB/Dβ：有限训练数据量带来的 loss。

模型参数 θ\thetaθ 是在每次训练运行中学习的；这里的 A,B,α,β,ffloorA,B,\alpha,\beta,f_{\mathrm{floor}}A,B,α,β,ffloor​ 是跨多次实验拟合出的 scaling-law 常数。也就是说，模型的 Loss 可以近似分解为一个基准值，以及两种由资源不足导致的额外 Loss。

给定预算：

6ND=C, 6ND=C, 6ND=C,

代入 D=C/(6N)D=C/(6N)D=C/(6N)：

f^C(N)=ffloor+ANα+B(6NC)β. \hat f_C(N) =f_{\mathrm{floor}} +\frac{A}{N^\alpha} +B\left(\frac{6N}{C}\right)^\beta. f^​C​(N)=ffloor​+NαA​+B(C6N​)β.

对 NNN 求导：

f^C′(N)=−αAN−α−1+βB(6C)βNβ−1. \hat f_C'(N)= -\alpha A N^{-\alpha-1} +\beta B\left(\frac6C\right)^\beta N^{\beta-1}. f^​C′​(N)=−αAN−α−1+βB(C6​)βNβ−1.

令导数为零并整理：

αANα=βB(6NC)β. \frac{\alpha A}{N^\alpha} =\beta B\left(\frac{6N}{C}\right)^\beta. NααA​=βB(C6N​)β.

因此：

Nα+β=αAβB(C6)β. N^{\alpha+\beta} =\frac{\alpha A}{\beta B} \left(\frac C6\right)^\beta. Nα+β=βBαA​(6C​)β.

最终：

N∗=(αAβB)1α+β(C6)βα+β \boxed{ N^{*}= \left(\frac{\alpha A}{\beta B}\right)^{\frac1{\alpha+\beta}} \left(\frac C6\right)^{\frac{\beta}{\alpha+\beta}} } N∗=(βBαA​)α+β1​(6C​)α+ββ​​

并且：

D∗=C∗6N∗. D^{*}=\frac{C^{*}}{6N^{*}}. D∗=6N∗C∗​.

所以：

N∗∝Cβα+β,D∗∝Cαα+β. N^{*}\propto C^{\frac{\beta}{\alpha+\beta}}, \qquad D^{*}\propto C^{\frac{\alpha}{\alpha+\beta}}. N∗∝Cα+ββ​,D∗∝Cα+βα​.

这里的最优解是 fitted loss model 下的最优 compute allocation，即，在所有满足 6ND=C6ND=C6ND=C 的方案中，使得预测 Loss f^(N,D)\hat f(N,D)f^​(N,D) 最小的那组模型参数量 N∗N^{*}N∗ 与训练数据量 D∗D^{*}D∗。

如果进一步采用 Chinchilla 根据经验得出的近似常数比例，可以得到：

N∗∝C,D∗∝C. N^{*}\propto\sqrt C,\qquad D^{*}\propto\sqrt C. N∗∝C​,D∗∝C​.

这意味着，如果 compute budget 增加四倍，推荐的 model size 和 training tokens 都增加约两倍。
