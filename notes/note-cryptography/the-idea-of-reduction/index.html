归约的概念

2023.06.02

The Idea of Reduction.

For problem AAA and BBB, if there exists a computable function fff that for all instance x∈Ax\in Ax∈A, A(x)=B(f(x))A(x)=B(f(x))A(x)=B(f(x)), we say that AAA could reduce to BBB.

Reduction (or simulation) is a powerful idea in computer science. Especially in cryptography, we use the idea of reduction to prove security of some cryptographic primitives.

We will illustrate the idea of reduction with a concrete example.

Example: Pseudo One-time Pad

Pseudo OTP:

Pseudo OTP solves OTP's drawback that secret key kkk needs to be as long as message mmm.

For m∈{0,1}nm\in \{0,1\}^nm∈{0,1}n, we expand a short key kkk to the length nnn with PRG: r:=G(k)r:=G(k)r:=G(k). Pseudo OTP encrypts as c:=m⊕G(k)c:=m\oplus G(k)c:=m⊕G(k).

Try to prove: Pseudo OTP Π\PiΠ is EAV-secure if GGG is a PRG.

We reduce "Pseudo OTP Π\PiΠ is EAV-secure" to "GGG is a PRG".

Construct a distinguisher DDD for GGG given A\mathscr{A}A attacking Π\PiΠ as its subroutine.

  • DDD runs A(1n)\mathscr{A}(1^n)A(1n).
  • A\mathscr{A}A outputs m0,m1m_0,m_1m0​,m1​.
  • DDD generates a random bit b∈{0,1}b\in\{0,1\}b∈{0,1} and obtain rrr from PRG challenger.
  • DDD sends mb⊕rm_b\oplus rmb​⊕r back to A\mathscr{A}A.
  • A\mathscr{A}A finally outputs b′b'b′.
  • If b′=bb'=bb′=b, DDD outputs 111, otherwise 000.

Considering the following 2 cases:

  • r←Unr\leftarrow U_{n}r←Un​ is truly random

    In this case, the view of A\mathscr{A}A is distributed identically to that of a true OTP protocol Π~\widetilde{\Pi}Π which obeys perfect secrecy, therefore Pr⁡r←Un[D(r)=1]=Pr⁡[b=b′]=Pr⁡[PrivKA,Π~eav(n)=1]=12\Pr_{r\leftarrow U_{n}}[D(r)=1]=\Pr[b=b']=\Pr[\mathtt{PrivK}^{eav}_{\mathscr{A}, \widetilde{\Pi}}(n)=1]=\frac{1}{2}Prr←Un​​[D(r)=1]=Pr[b=b′]=Pr[PrivKA,Πeav​(n)=1]=21​.

  • r:=G(s)r:=G(s)r:=G(s) for some sss (rrr is pseudorandom)

    In this case, the view of A\mathscr{A}A when run as a subroutine of DDD is that of the adversarial indistinguishability experiment of the Pseudo OTP Π\PiΠ, therefore Pr⁡s←Um[D(G(s))=1]=Pr⁡[b=b′]=Pr⁡[PrivKA,Πeav(n)=1]\Pr_{s\leftarrow U_m}[D(G(s))=1]=\Pr[b=b']=\Pr[\mathtt{PrivK}^{eav}_{\mathscr{A}, \Pi}(n)=1]Prs←Um​​[D(G(s))=1]=Pr[b=b′]=Pr[PrivKA,Πeav​(n)=1].

Reduction process:

Since GGG is PRG: ∣Pr⁡r←Un[D(r)=1]−Pr⁡s←Um[D(G(s))=1]∣≤ε(n)|\Pr_{r\leftarrow U_{n}}[D(r)=1]-\Pr_{s\leftarrow U_m}[D(G(s))=1]|\leq \varepsilon(n)∣Prr←Un​​[D(r)=1]−Prs←Um​​[D(G(s))=1]∣≤ε(n).

From the 2 equality above: ∣Pr⁡[PrivKA,Πeav(n)=1]−Pr⁡[PrivKA,Π~eav(n)=1]∣≤ε(n)|\Pr[\mathtt{PrivK}^{eav}_{\mathscr{A}, \Pi}(n)=1]-\Pr[\mathtt{PrivK}^{eav}_{\mathscr{A}, \widetilde{\Pi}}(n)=1]|\leq \varepsilon(n)∣Pr[PrivKA,Πeav​(n)=1]−Pr[PrivKA,Πeav​(n)=1]∣≤ε(n).

Therefore Pr⁡[PrivKA,Πeav(n)=1]≤ε(n)+12\Pr[\mathtt{PrivK}^{eav}_{\mathscr{A}, \Pi}(n)=1]\leq \varepsilon(n)+\frac{1}{2}Pr[PrivKA,Πeav​(n)=1]≤ε(n)+21​, which indicates that pseudo OTP is EAV-secure.

Reduction Logic

Reduction provides an abstraction.

Understand the abstraction is the key to understand reduction.

If we want to reduce the security of Π′\Pi'Π′ to the security of Π\PiΠ, we need to construct an adversary S\mathscr{S}S for Π\PiΠ given the adversary A\mathscr{A}A for Π′\Pi'Π′ as its subroutine, which is to say, S\mathscr{S}S employs (runs) A\mathscr{A}A as a black box abstraction function (Encapsulation).

The reduction involves 4 logic statements:

  • p:p:p: ∃ S\exists\ \mathscr{S}∃ S that is able to attack Π\PiΠ with non-negligible advantage.
  • q:q:q: ∃ A\exists \ \mathscr{A}∃ A that is able to attack Π′\Pi'Π′ with non-negligible advantage.
  • ¬p:\lnot p:¬p: Π\PiΠ is secure, which means S\mathscr{S}S that could successfully attack Π\PiΠ is NOT exist.
  • ¬q:\lnot q:¬q: Π′\Pi'Π′ is secure, which means A\mathscr{A}A that could successfully attack Π′\Pi'Π′ is NOT exist.

If S\mathscr{S}S is constructed successfully, it will be able to attack Π\PiΠ with non-negligible advantage. Therefore we could conclude that if A\mathscr{A}A could attack Π′\Pi'Π′ successfully, S\mathscr{S}S (which takes A\mathscr{A}A as its subroutine) could attack Π\PiΠ. The corresponding logic is q→pq\to pq→p.

According to the contrapositive statement, we have ¬p→¬q\lnot p\to \lnot q¬p→¬q, which implys that the security of Π\PiΠ guarantees the security of Π′\Pi'Π′. Therefore, the reduction is completed: we reduce the security of Π′\Pi'Π′ to the security of Π\PiΠ.

Contrapositive argument:

The contrapositive of the conditional statement "If ppp then qqq. " is "If not qqq then not ppp".

The logical equivalence could be expressed by p→q  ⟺  ¬q→¬pp\to q \iff \lnot q\to \lnot pp→q⟺¬q→¬p.

Eureka moment!

归约应该是整个密码学安全性证明中的核心思想之一。

第一次接触归约时 (即上文中提到的对伪一次性密码本安全性的证明) 真的思考了超级久才把整个逻辑捋清。但一旦想明白了就会觉得实在是巧妙：假设攻击方案 AAA 的敌手存在，我们直接将该敌手封装 (encapsulate) 起来作为攻击已知安全的方案 BBB 的敌手的子程序 (subroutine)。如果构建成功，根据逆否命题就能完成归约。

归约证明最难的地方应该在于 simulator S\mathscr{S}S 的设计：其与子程序 A\mathscr{A}A 的交互必须是黑盒式的，且无法让 A\mathscr{A}A 察觉到与其互动的并不是 challenger C\mathscr{C}C，而是某个 simulator S\mathscr{S}S。

在整个课程的学习中了解到了很多很妙的归约，例如 Pseudorandom function/permutation 构建的加密方案的 CPA 安全性证明，Hash-MAC 与 Hash-Sign 方案的安全性证明，Authenticate encryption 的安全性证明，RSA 硬核谓词 (Hard-core predicates) 的证明，RSA-FDH (Full-Domain Hash) signature 的不可伪造性证明，Fiat-Shamir transformation 的证明，Schnorr identification 的安全性证明……
