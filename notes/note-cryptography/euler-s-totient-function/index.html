Definition. Euler's Totient Function φ(N)\varphi(N)φ(N) is defined as the number of positive integers ≤N\leq N≤N that are relatively prime to NNN, where 111 is counted as being relatively prime to all integers.

Euler's Theorem

Theorem. Let nnn be a positive integer, and let aaa be an integer that is relatively prime to nnn. Then aφ(n)≡1(modn)a^{\varphi(n)}\equiv 1\pmod{n}aφ(n)≡1(modn), where φ(n)\varphi(n)φ(n) is Euler's totient function of nnn.

Since gcd⁡(a,n)=1\gcd(a,n)=1gcd(a,n)=1, aaa is invertible modulo nnn. According to Euler's Theorem, aφ(n)≡1(modn)a^{\varphi(n)}\equiv 1\pmod{n}aφ(n)≡1(modn). Therefore a×aφ(n)−1≡1(modn)a\times a^{\varphi(n)-1}\equiv 1\pmod{n}a×aφ(n)−1≡1(modn). aφ(n)−1a^{\varphi(n)-1}aφ(n)−1 is a multiplicative inverse of aaa modulo nnn.

这里主要想讲下关于欧拉函数的一般公式：φ(n)=nΠp∣n(1−1p)\varphi(n)=n\Pi_{p|n}(1-\frac{1}{p})φ(n)=nΠp∣n​(1−p1​)。本质上这是一个容斥原理的应用。

举个例子就容易理解了：假设 nnn 只有两个质因子 p1,p2p_1,p_2p1​,p2​，那么展开上式可得 φ(n)=n−np1−np2+np1p2\varphi(n)=n-\frac{n}{p_1}-\frac{n}{p_2}+\frac{n}{p_1p_2}φ(n)=n−p1​n​−p2​n​+p1​p2​n​. 用自然语言描述，即在 1−n1-n1−n 中与 nnn 互质的数的个数为 nnn 减去是 p1p_1p1​ 倍数的数的个数，再减去是 p2p_2p2​ 倍数的数的个数。此时，是 p1p2p_1p_2p1​p2​ 倍数的数将会被重复减去两次；根据容斥原理，我们将多减的个数重新加回来，因此最后再加上是 p1p2p_1p_2p1​p2​ 倍数的数的个数。
