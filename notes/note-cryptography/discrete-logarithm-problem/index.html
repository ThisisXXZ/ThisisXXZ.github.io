离散对数问题

2023.06.05

Discrete Logarithm Problem.

Fix a cyclic group G\mathbb{G}G of order qqq, and generator g∈Gg\in\mathbb{G}g∈G. We know that {g0,g1,...,gq−1}=G\{g^0,g^1,...,g^{q-1}\}=\mathbb{G}{g0,g1,...,gq−1}=G.

Equilently, for every h∈Gh\in\mathbb{G}h∈G, there is a unique x∈Zqx\in \mathbb{Z}_qx∈Zq​, such that gx=hg^x=hgx=h. We define log⁡gh\log_g{h}logg​h to be this xxx. This is the discrete logarithm of hhh with respect to ggg in the group G\mathbb{G}G.

Discrete Logarithm problem in G\mathbb{G}G: Given g∈Gg\in \mathbb{G}g∈G and uniform h∈Gh\in \mathbb{G}h∈G, compute log⁡gh\log_g{h}logg​h.

Discrete-Logarithm Experiment

Similarly, we have the discrete-logarithm experiment DLogA,G(n)\mathtt{DLog}_{\mathscr{A}, \mathscr{G}} (n)DLogA,G​(n) where G\mathscr{G}G is an efficient group-generation algorithm that, on input 1n1^n1n, outputs a cyclic group G\mathbb{G}G, its order qqq, and a generator ggg.

Adversary A\mathscr{A}A with G,q,g\mathbb{G},q,gG,q,g and a uniform h∈Gh\in\mathbb{G}h∈G needs to efficiently compute correponding xxx.

Definition. RSA problem is hard relative to G\mathscr{G}G if for all probabilistic polynomial time algorithm A\mathscr{A}A, there exists a negligible ε(n)\varepsilon(n)ε(n) that Pr⁡[DLogA,G(n)=1]≤ε(n)\Pr[\mathtt{DLog}_{\mathscr{A}, \mathscr{G}}(n)=1]\leq \varepsilon(n)Pr[DLogA,G​(n)=1]≤ε(n).

The Discrete Logarithm Assumption is the assumption that there exists a group-generation algorithm G\mathscr{G}G relative to which the Discrete Logarithm problem is hard.

Eureka moment!

离散对数问题本质上是模意义下的对数运算。另外还需要注意一点，无论是 RSA 实验还是离散对数实验，对敌手的挑战 (challenge) 都是均匀随机 (uniform) 的。

其实，RSA 问题 (模意义下的开次方运算) 与离散问题 (模意义下的对数运算) 均可以视为幂运算 h=gxh=g^xh=gx 的逆运算：RSA 问题给出指数 xxx，要求由 hhh 计算底数 g=h1/xg=h^{1/x}g=h1/x；而离散对数问题给出底数 ggg，要求由 hhh 计算指数 x=log⁡ghx=\log_g hx=logg​h。
