MOS 器件的模式

MOS 晶体管是一种多数载流子（majority-carrier）器件：源极与漏极之间导电沟道中的电流由施加在栅极上的电压控制。

以 nMOS 为例：

=> 累积（accumulation）：栅极加负电压 Vg<0V_g<0Vg​<0，因此栅极上带负电。体区中带正电的可移动空穴被吸引到栅极下方区域。

=> 耗尽（depletion）：栅极加较小的正电压 0<Vg<Vt0<V_g<V_t0<Vg​<Vt​，因此栅极上带一定正电。体区中的空穴被排斥离开栅极下方区域，在栅下形成耗尽区（depletion region）。

=> 反型（inversion）：栅极电压超过临界阈值 Vg≥VtV_g\geq V_tVg​≥Vt​，在栅极上吸引更多正电荷，空穴被进一步排斥，自由电子被吸引到栅下形成导电电子层，被称为反型层（inversion region）。

引入源极与漏极。

=> 截止（cutoff），或关断（OFF）：栅源电压 Vgs<VtV_{gs}<V_tVgs​<Vt​。源极与体区均接地 Vs=0V_s=0Vs​=0，以防止 p 型体区与两个 n 型源漏区组成的 PN 结正向偏置。

考虑给定某恒定栅压，使栅源电压 Vgs≥VtV_{gs}\geq V_tVgs​≥Vt​，源漏之间反型层构成沟道（channel），MOS 导通（ON）。

=> 线性（linear）：漏极施加较小的电压造成漏源间电势差 Vds>0V_{ds}>0Vds​>0，电流 IdsI_{ds}Ids​ 形成，与 VdsV_{ds}Vds​ 成正比。

=> 饱和（saturation）：漏极电压增加至使 Vgd=Vgs−Vds<VtV_{gd}=V_{gs}-V_{ds}<V_tVgd​=Vgs​−Vds​<Vt​，沟道在近漏极 某处* 发生夹断（pinch-off），不再处于反型状态；但导电仍通过漏源电势差下的电子漂移实现。电子到达沟道末端时被注入到漏极附近的耗尽区，并在强电场作用下加速流向漏极。此时的 IdsI_{ds}Ids​ 仅由 VgsV_{gs}Vgs​ 控制（到达夹断点之前能够注入的电子数量仅由栅压决定），不再受 VdsV_{ds}Vds​ 影响。

不理想的 IV 表现

实际的 MOS 会出现各种与长沟道模型不符的不理想 IV 表现（nonideal IV effects）。

速度饱和（velocity saturation）：高横向电场 (Vds/L)(V_{ds}/L)(Vds​/L) 下，载流子的速度不再与场强成正比，(5)(5)(5) 失效 => 高漏压 VdsV_{ds}Vds​ 下 IdsI_{ds}Ids​ 低于预测值

移动力衰减（mobility degradation）：高垂直电场 (Vgs/tox)(V_{gs}/t_{ox})(Vgs​/tox​) 下，载流子更加分散 => 高栅压 VgsV_{gs}Vgs​ 下 IdsI_{ds}Ids​ 低于预测值

沟道长度调制（channel length modulation）：高漏压 VdsV_{ds}Vds​ 下，漏极附近的耗尽层增大，沟道长度 LLL 缩短 => 饱和电流 IdstatI_{dstat}Idstat​ 随 VdsV_{ds}Vds​ 的增加略微增加

非恒定的阈值 VtV_tVt​：

  • 体效应（body effect）：源体间电势差增大也会抬升 VtV_tVt​
  • 漏致势垒降低（drain-induced barrier lowering）：增大漏压会降低 VtV_tVt​
  • 短沟道效应（short channel effects）：沟道变长将抬升 VtV_tVt​

泄露（leakage）现象：在关断的 MOS 中仍有电流流动

  • 亚阈值导通（subthreshold conduction）：Vgs<VtV_{gs}<V_tVgs​<Vt​ 时，电流以指数形式下降而不是突变为 0，因此关断后会在极短时间内有电流导通
  • 结泄露（junction leakage）：源漏极与体（衬底或井）间的反向偏置 PN 结有微小电流
  • 门泄露（gate leakage）：栅氧极薄时将发生电子隧穿（electron tunneling）有微小栅极电流

温度影响：高温 => 低移动力，低 VtV_tVt​，导通时低 IdsI_{ds}Ids​，关断时高泄露；MOS 特性退化。

关于 pMOS

见上图右侧的曲线，把 VdsV_{ds}Vds​ 换成 VsdV_{sd}Vsd​，IdsI_{ds}Ids​ 换成 IsdI_{sd}Isd​，整个曲线镜像到第一象限，就与 nMOS 同样是开口向下的二次曲线了。但很明显开口比 nMOS 要小，这是因为空穴移动力 μp\mu_{p}μp​ 约是电子移动力 μn\mu_{n}μn​ 的一半。

这也呼应了之前提到的，pMOS 与 nMOS 提供同样的电流，宽度须是后者的两倍。
