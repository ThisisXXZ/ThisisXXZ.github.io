Elementary Sorts

获益良多，对 ∼N2\sim N^2∼N2 的基础排序算法 (插排，希尔排序) 有了新的认识。之前一直觉得有快排就够了 (N 方的排序算法是什么臭鱼烂虾)，学完之后才发现这样的想法是多么傲慢。这些算法里蕴含的排序思想，和无数计算机科学家 (包括教授 Sedgewick) 尝试改进优化所做的努力，都是难能可贵的。

排序算法在 Java 中的实现离不开 Comparable 接口。有关这部分的内容 (包括下文所用到的 less 与 exch 辅助方法) 在 Java 配套笔记中进行记录。

Selection Sort

In iteration iii, find index minminmin of smallest remaining entry. Then swap aia_iai​ and amina_{min}amin​.

Proposition. Selection sort uses 0+1+...+(N−1)∼N2/20+1+...+(N-1)\sim N^2/20+1+...+(N−1)∼N2/2 compares and NNN exchanges.

The running time is intensive to input: it takes quadratic time even if input is sorted.

Knuth's shuffle is structurally similar to selection sort. It is used to generate random shuffles.

Insertion Sort

In iteration iii, swap aia_iai​ with each larger entry to its left.

Insertion sort is NOT intensive to input.

  • Best case. ascending arrays: it makes N−1N-1N−1 compares and 000 exchanges.
  • Worst case. descending arrays: it makes ∼12N2\sim \frac{1}{2}N^2∼21​N2 compares and ∼12N2\sim \frac{1}{2}N^2∼21​N2 exchanges.

Note that for partially-sorted arrays, insertion sort runs in linear time.

This is because number of exchanges equals the number of inversions, and numbers of compares === exchanges +(N−1)+(N-1)+(N−1).

Def 1. An inversion is a pair of keys that are out of order.

Def 2. An array is partially sorted if the number of inversions is ≤cN\leq cN≤cN.

Shellsort

Idea. Move entries more than one position at a time by hhh-sorting the array.

Shellsort. [Shell 1959] Repeatedly hhh-sort the array with a decreasing sequence of values of hhh.

We use insertion sort with stride length hhh to hhh-sort an array. why choosing insertion sort:

  • Big increments →\to→ small subarray.
  • Small increments →\to→ nearly in order. (insertion sort is fast when array is partially sorted)

Note the fact that a ggg-sorted array remains ggg-sorted after hhh-sorting it.

An efficient shellsort scheme depends on a proper increment sequence.

  • 3x+13x+13x+1. (most commonly used) 1,4,13,40,121,364,...1,4,13,40,121,364,...1,4,13,40,121,364,...
  • Sedgewick. (tough to beat in empirical studies) 1,5,19,41,109,...1,5,19,41,109,...1,5,19,41,109,...

The worst-case number of compares used by shellsort with the 3x+13x+13x+1 increments is O(N3/2)O(N^{3/2})O(N3/2).

However, accurate model for shellsort has NOT yet been discovered. Maybe some better increment sequences are still left for discover......!

Also note that though shellsort uses insertion sort to hhh-sort the array, it is NOT stable.

A stable sort preserves the relative order of items with equal keys.

Insertion sort and merge sort are stable; Selection sort and shellsort are not.
