Closest Pair

平面最近点对问题：nnn 个点 (x1,y1),(x2,y2),...,(xn,yn)(x_1,y_1),(x_2,y_2),...,(x_n,y_n)(x1​,y1​),(x2​,y2​),...,(xn​,yn​)，输出距离最近的点对。

解法还是很巧妙的，仍然是分治思想。

  • Divide: 把所有点按照 xxx 坐标排序，画出中线 LLL 使得其两侧均有 n/2n/2n/2 个点。这个过程是 O(nlog⁡n)O(n\log n)O(nlogn) 的。
  • Recurse: 递归找到左组内以及右组内的最近点距 δL,δR\delta_L,\delta_RδL​,δR​
  • Combine: 求出左右组间的最近点距 δmid\delta_{mid}δmid​

显然，如何找到组间的最近点距需要仔细设计。令 δ=min⁡(δL,δR)\delta=\min(\delta_L,\delta_R)δ=min(δL​,δR​)，只考虑 x∈[L−δ,L+δ]x\in[L-\delta,L+\delta]x∈[L−δ,L+δ] 区间中的点，把它们按照 yyy 坐标排序，得到点序列 {p1,p2,...,pm}\{p_1,p_2,...,p_m\}{p1​,p2​,...,pm​}。对于 pip_ipi​，只需要记录它和 pi+1,pi+2,...,pi+7p_{i+1},p_{i+2},...,p_{i+7}pi+1​,pi+2​,...,pi+7​ 随后这 7 个点的距离。

为什么偏偏是 7 个点？这个数字基于一个重要的结论：

把该正方形划分为四个边长为 δ/2\delta/2δ/2 的子正方形，在子正方形中，任意点距都 ≤δ/2<δ\leq \delta/\sqrt{2}<\delta≤δ/2​<δ；因此每个子正方形中最多只能有一个点，否则就将与已知的单侧最小点距为 δ\deltaδ 的结论相冲突。所以，这整个正方形中最多有 4 个点。

现在考虑组间区间中的一个点 pi=(xi,yi)p_i=(x_i,y_i)pi​=(xi​,yi​)，将它与 y>yiy>y_iy>yi​ 的点构成点对；如果比 δ\deltaδ 更小的点距存在，对应的点一定位于 [L−δ∼L+δ,yi∼yi+δ][L-\delta \sim L+\delta,y_i\sim y_i+\delta][L−δ∼L+δ,yi​∼yi​+δ] 这一长方形内。该长方形由左右两侧两个 δ×δ\delta\times \deltaδ×δ 的正方形组成，根据上文得出的结论，其中最多含有 4×2=84\times 2=84×2=8 个点。除去 pip_ipi​ 本身，需要比较的点最多只有 7 个。

确实巧妙！这个算法的复杂度递归形式是 T(n)=2T(n/2)+O(nlog⁡n)T(n)=2T(n/2)+O(n\log n)T(n)=2T(n/2)+O(nlogn) [bottleneck 是对组间区间中的点按照 yyy 坐标排序]，解得 T(n)=O(nlog⁡2n)T(n)=O(n\log^2 n)T(n)=O(nlog2n)。

DFS & BFS

无甚好讲，主要是一些名词解释。

无向图的 DFS 树。

  • DFS 树的树边 tree edges.
  • foward edges. node →\to→ a non-child descendent.
  • back edges. node →\to→ ancestor.
  • cross edges. node →\to→ a node that has been already explored (explored: pre-ordered & post-ordered).

应用：

  • DFS 判环 (找 back edges)
  • DAG 的拓扑排序：DFS 后序遍历的逆序。起始节点入度为 0。
  • SCC：
    • 初始化：求反图 GRG_RGR​ 并 DFS 一次得到后序遍历 post\text{post}post。
    • 求 SCC：回到图 GGG，取当前图中 post[x]\text{post}[x]post[x] 最大的点 xxx 作为起始点，DFS 一遍找到包含 xxx 的 SCC，标号，并从 GGG 中删除该 SCC (点和所有连向/连出的边)。重复此过程直至所有 SCC 被找出。
    • 原理：source SCC 易找到 (post[x]\text{post}[x]post[x] 最大的点 xxx 一定在 source SCC 中) 但 sink SCC 不易找到。但 GGG 的 sink SCC 就是 GRG^RGR 的 source SCC。

SPT (Shortest Path Tree) 最短路径树：最短路径生成的树。

Dijkstra 算法的本质就是不断扩展 SPT 直到图上的点均被覆盖。每次迭代，找到离最短路径树距离最近的节点 vvv (堆优化)，加入 SPT，并由 vvv 更新 SPT 到余下所有点的距离。复杂度 O((∣E∣+∣V∣)log⁡∣V∣)O((|E|+|V|)\log |V|)O((∣E∣+∣V∣)log∣V∣)。[边复杂度对应入堆，点复杂度对应出堆]

Bellman-Ford 算法。由于图中有负权边 (但无负环)，Dijkstra 设计的 "clever order" 失效了，因此需要回到 “stupid way”。考虑到任意一条最短路长度 ≤∣V∣−1\leq |V|-1≤∣V∣−1，将所有边松弛 ∣V∣−1|V|-1∣V∣−1 次即可。复杂度 O(∣V∣∣E∣)O(|V||E|)O(∣V∣∣E∣)。队列优化是 SPFA。

Floyd-Warshall 算法。多源最短路，有负权边无负环。f[i,j,k]f[i,j,k]f[i,j,k] 表示从 iii 到 jjj，考虑 1..k1..k1..k 作为中间点的最短路。

  • f[i,j,k]=min⁡(f[i,j,k−1],f[i,k,k−1]+f[k,j,k−1])f[i,j,k]=\min(f[i,j,k-1], f[i,k,k-1]+f[k,j,k-1])f[i,j,k]=min(f[i,j,k−1],f[i,k,k−1]+f[k,j,k−1])。

DAG 求最短路。很明显，按照拓扑序松弛即可。复杂度 O(∣V∣+∣E∣)O(|V|+|E|)O(∣V∣+∣E∣)。

介绍了几个简单的贪心模型。

任务调度 (Job scheduling)：有一系列任务。任务 iii 需要 tit_iti​ 时间，deadline 是 did_idi​。完成所有任务是否可行？

贪心：did_idi​ 越早，任务排序越前。证明：

  • 若按照该顺序，任务 jjj 无法在 djd_jdj​ 前完成，说明 1..dj1..d_j1..dj​ 时间区间内需要完成的任务量 s1+s2+...+sj>djs_1+s_2+{...}+s_j> d_js1​+s2​+...+sj​>dj​。无解。

区间调度 (Interval scheduling)：有一系列区间 [si,fi][s_i,f_i][si​,fi​]，选择尽量多的区间使他们互不相交。

贪心：结束时间 fif_ifi​ 越早，任务排序越前。证明：

  • 令 i1,i2,...,iki_1,i_2,...,i_ki1​,i2​,...,ik​ 为贪心解，j1,j2,...,jmj_1,j_2,...,j_mj1​,j2​,...,jm​ 为最优解。
  • rrr 为贪心解与最优解的最大公共前缀和的长度，即 i1=j1,i2=j2,...,ir=jri_1=j_1,i_2=j_2,...,i_r=j_ri1​=j1​,i2​=j2​,...,ir​=jr​。
  • 考虑 ir+1i_{r+1}ir+1​ 与 jr+1j_{r+1}jr+1​；根据贪心策略，ir+1i_{r+1}ir+1​ 的结束时间一定不晚于 jr+1j_{r+1}jr+1​ 的结束时间。那么，将最优解中的 jr+1j_{r+1}jr+1​ 换成 ir+1i_{r+1}ir+1​ 并不会影响后续的选择。
